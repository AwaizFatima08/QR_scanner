# ScanLink: QR & Barcode Scanner

Android app by HomiLabs. Scan a QR code or barcode with the camera — or pick a picture from your gallery — and open
it: web links in your browser, phone numbers in the dialler, emails, text messages, map locations, Wi-Fi details,
contact cards and product barcodes (web lookup). No login, no account; history stays on the phone.

Built with Flutter (`mobile_scanner` / ML Kit, `image_picker`, `url_launcher`). Free with Google AdMob ads.

```
flutter test
flutter run
```

See `CLAUDE.md` for decisions, commands and release steps, and `docs/ads.md` for the ad rules.
